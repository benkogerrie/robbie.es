The problem

Important company changes are easy to miss.

For a selected set of companies, changes in status, insolvency, legal form, activity or location can matter immediately — but checking the register by hand is slow and inconsistent.

The need was not another dashboard. It was a reliable way to notice the change as soon as it appears.

The useful moment is not when you remember to check. It is when the register changes.
What I built

A monitoring and alert service for selected companies.

KVK Monitor watches a defined company list across multiple register fields and sends a Telegram alert when a relevant change is detected.

It is shaped around operational awareness: clear signals, fast delivery, and a shortlist that actually matters.

  • Selected-company watchlist
  • Multi-field register monitoring
  • Immediate Telegram alerts on relevant changes
  • Working prototype built around a real workflow
Signals monitored

Six fields that trigger an alert.

The service monitors a focused set of commercially relevant register fields — not the entire register dump.

How it works

From watchlist to alert in one loop.

Companies are added to a monitoring list. The prototype checks the watched register fields against that list and pushes a concise Telegram alert when a change appears.

The goal is practical awareness: know what changed, for which company, without keeping a manual register check running in the background.

  • Define the companies that matter
  • Monitor the selected register fields
  • Deliver each relevant change through Telegram
  • Act without opening the register by hand
