The problem

Manually checking filings does not scale.

For a selected set of companies, knowing when new annual accounts appear is useful — but repeatedly checking the register is slow, easy to miss and hard to keep consistent.

The need was simple: notice the filing as soon as it becomes available, without turning that into a recurring manual task.

The useful moment is not when you remember to check. It is when the filing appears.
What I built

A focused monitor for selected companies.

KVK Monitor is a working prototype that watches a defined company list and sends a Telegram alert when new annual accounts are filed.

It is deliberately narrow: one signal, one delivery channel, and a clear operational outcome.

  • Selected-company watchlist
  • Monitoring for new annual-accounts filings
  • Immediate Telegram notification when a match appears
  • Lightweight prototype shaped around a real workflow
How it works

From watchlist to alert in one loop.

Companies are added to a monitoring list. The prototype checks for new annual accounts against that list and pushes a concise alert when a filing is found.

The goal is not a broad dashboard. It is a reliable signal that removes the need to keep checking by hand.

  • Define the companies that matter
  • Monitor filings for that shortlist
  • Deliver the update through Telegram
  • Act on the filing without manual register checks
Where it stands

A working prototype with a clear job.

Live prototype The monitoring loop and Telegram delivery are already working for a selected set of companies.
Why it mattered

Less checking. Faster awareness.

No manual loop

Narrow by design
